# PdM Baseline Playground

Interactive companions for *ML for Predictive Maintenance with KNIME*, Day 3-4.

- [`index.html`](https://waranyuwongseree.github.io/pdm-baseline-playground/) — five baseline
  methods for anomaly detection on one pump (Train / Test / Alarm rules), including the
  classroom pump preset packed from the course's own scenario files
- [`PDM_BASELINE_LAB_MANUAL.html`](https://waranyuwongseree.github.io/pdm-baseline-playground/PDM_BASELINE_LAB_MANUAL.html)
  — 11 experiments with fillable record sheets (answers autosave in the browser)
- [`modes.html`](https://waranyuwongseree.github.io/pdm-baseline-playground/modes.html)
  — Day 4: operating modes and many sensors (k-Means / silhouette / PCA T² and Q)

Every file is self-contained; sources and gates live in the course repositories.
